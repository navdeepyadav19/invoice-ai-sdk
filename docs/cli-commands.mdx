## invoice-ai

```text
Usage: invoice-ai [options] [command]

Invoice-AI from your terminal. Log in once, then manage customers, products,
prices, invoices, invoice items and webhooks.

Options:
  -v, --version                  print the CLI version
  --api-key <key>                API key to use (overrides INVOICE_AI_API_KEY
                                 and the saved profile)
  -p, --profile <name>           saved profile to use (see `invoice-ai switch`)
  --json                         print raw JSON (default when output is piped)
  --format <format>              output format (choices: "table", "json", "csv")
  -y, --yes                      skip confirmation prompts
  --debug                        log each API request and retry (secrets
                                 redacted)
  --no-color                     disable colors (also honours NO_COLOR)
  -h, --help                     show help

Commands:
  login [options]                Log in with your browser (or store a key passed
                                 with --api-key)
  logout                         Revoke this profile’s key on the server and
                                 forget it locally
  whoami                         Show the account, key and profile in use
  switch [profile]               Make another logged-in profile the default
                                 (lists profiles without an argument)
  customers                      Manage customers (the people and companies you
                                 bill)
  products                       Manage products in your catalog
  prices                         Manage prices (what a product costs, per
                                 currency)
  invoices                       Create, send and manage invoices
  invoice-items                  Add, inspect and remove the lines of a draft
                                 invoice
  webhooks                       Manage webhook endpoints and test your receiver
  api [options] <method> <path>  Call any API endpoint directly and print the
                                 JSON response
  open [page] [id]               Open the web app: dashboard, invoices,
                                 customers, products, settings, api-keys,
                                 webhooks, or "invoice <id>"
  docs [topic]                   Open the documentation (home, quickstart, auth,
                                 errors, idempotency, pagination, rate-limits,
                                 ids, lifecycle, webhooks, api, cli, changelog)
  completion <shell>             Print a shell completion script (bash, zsh or
                                 fish)

Examples:
  $ invoice-ai login
  $ invoice-ai invoices create
  $ invoice-ai invoices list --status open
  $ invoice-ai customers create --name "Acme" --email ap@acme.com
  $ invoice-ai api GET /business

Environment:
  INVOICE_AI_API_KEY      API key (for CI); beats the saved profile
  INVOICE_AI_PROFILE      profile to use when --profile isn't given
  INVOICE_AI_BASE_URL     API base URL, e.g. http://localhost:3000/api/v1
  INVOICE_AI_NO_KEYCHAIN  keep keys in the config file, not the OS keychain
  NO_COLOR                disable colors

Exit codes: 0 ok · 1 API error · 2 usage error · 3 auth · 4 rate limited
```

## invoice-ai login

```text
Usage: invoice-ai login [options]

Log in with your browser (or store a key passed with --api-key)

Options:
  --no-browser          print the login URL instead of opening a browser
  -h, --help            show help


Opens the Invoice-AI authorize page, where you approve this device. A new API key
is created for it and saved in your OS keychain (or ~/.config/invoice-ai/config.json,

  $ invoice-ai login
  $ invoice-ai login --profile staging
  $ invoice-ai login --api-key inv_live_…        # no browser; verifies and stores the key
```

## invoice-ai invoices create

```text
Usage: invoice-ai invoices create [options]

Create an invoice: a guided wizard with no flags, or scripted with flags

Options:
  --finalize                    finalize it right away (assigns a number, locks
                                the lines)
  --send                        finalize and email it to the customer
  --no-interactive              never start the wizard
  --customer <id>               customer to bill (cus_…)
  --price <id>                  add a line from this price (repeatable)

                                (repeatable, default 1)
  --currency <code>             invoice currency (defaults to your business
                                currency)
  --due-date <YYYY-MM-DD>       due date
  --days-until-due <n>          due this many days after finalizing
  --description <text>          memo shown on the invoice
  --footer <text>               footer text
  --collection-method <method>  send_invoice (default) or charge_automatically
  -d, --data <json>             request body as JSON, @file.json or @- for stdin
                                (flags override its fields)
  -h, --help                    show help


Examples:
  $ invoice-ai invoices create                      # guided wizard
  $ invoice-ai invoices create --customer cus_123 --price price_abc --qty 2 --send
```

## invoice-ai invoice-items create

```text
Usage: invoice-ai invoice-items create [options]

Add a line to a draft: from a --price, or ad hoc with --description and an
amount

Options:
  --invoice <id>         the draft to add to (in_…), required
  --price <id>           bill from this catalog price (fills description, amount
                         and tax rate)
  --description <text>   what you are billing for (required without --price)
  --qty <n>              quantity, may be fractional (default 1)
  --unit <unit>          unit of measure (default NOS) (choices: "NOS", "PCS",
                         "KGS", "GMS", "LTR", "MTR", "SQF", "SQM", "HRS", "DAY",
                         "MON", "BOX", "SET", "OTH")

                         invoice currency)
  --unit-amount <minor>  unit amount in minor units, e.g. 2500 for $25.00
  --currency <code>      currency for --amount (defaults to the invoice
                         currency)
  --discount <percent>   discount percentage applied before tax
  --tax-rate <percent>   tax percentage added on top (defaults to the price
                         rate, or 0)
  -d, --data <json>      request body as JSON, @file.json or @- for stdin (flags
                         override its fields)
  -h, --help             show help


Examples:
  $ invoice-ai invoice-items create --invoice in_123 --price price_abc --qty 3
  $ invoice-ai invoice-items create --invoice in_123 --description "Rush fee" --amount 50
```

## invoice-ai webhooks test

```text
Usage: invoice-ai webhooks test [options] <url>

Send a correctly signed sample event to your receiver (no API key needed)

Options:
  --secret <whsec>      the endpoint's signing secret (whsec_…)
```

## invoice-ai api

```text
Usage: invoice-ai api [options] <method> <path>

Call any API endpoint directly and print the JSON response

Options:
  -d, --data <json>        request body as JSON, @file.json or @- for stdin
  -q, --query <key=value>  query parameter (repeatable)
  --idempotency-key <key>  Idempotency-Key for POST (default: generated)
  -h, --help               show help


The path is relative to /api/v1 (a leading /api/v1 is accepted too).

Examples:
  $ invoice-ai api GET /business
  $ invoice-ai api GET /invoices --query status=open --query limit=5
  $ invoice-ai api POST /customers --data '{"name":"Acme","email":"ap@acme.com"}'
  $ invoice-ai api PATCH /customers/cus_123 --data @patch.json
```
